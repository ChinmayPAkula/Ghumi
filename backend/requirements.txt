# Hotelbeds are not used — Amadeus's self-service/test tier was
# decommissioned 2026-07-17 (Enterprise API only now), and Hotelbeds'
# sandbox quota proved too restrictive for active development. The legacy
# googlemaps SDK is not used either — its places()/geocode() methods hit
# the old Places API, which isn't enabled on an unbilled API key.
